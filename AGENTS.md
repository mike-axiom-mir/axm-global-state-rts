# AXM Global State RTS — contributor boundary

## Constitutional merge gate

Internal AXM integration is evaluated through four roots:

1. Truth
2. Agency / non-domination
3. Continuity
4. Wisdom before speed

Mike is the founder and direction-setter, not the internal constitutional merge gate. Technical permission is not CANON authority. There is no automatic CANON.

## Source integrity

`planet-upstream` is a pinned import of `mike-axiom-mir/foundation-planet-experiments`.

- Do not silently rewrite the source Planet repository from this game.
- Game-specific experiments belong in this repository.
- Preserve the upstream commit pin and provenance when updating the imported Planet.
- If the game needs to alter Planet behavior, prefer a bounded game seam/adapter first; vendor or fork only when a direct source divergence is genuinely required and record it explicitly.

## World-state rule

Separate what exists from how it is rendered.

- canonical world/game state is authoritative;
- globe view, local RTS view, meshes, particles, UI, LOD, and mobile/desktop render paths are expressions of that state;
- a cheaper renderer may simplify expression but may not silently erase or invent authoritative facts.

## Mass-macro rule

Before adding a mechanic, ask whether it still makes sense with tens or hundreds of thousands of units.

Prefer aggregate arithmetic, bounded automation, deterministic state, and strategic decisions over per-object chores and persistent debris.

## Status language

Use honest labels: `EXPERIMENTAL`, `TEST`, `WORKING`, `CANON`, `SHELL`, `BROKEN`.

Do not claim browser rendering, multiplayer, scale, balance, or persistence has been verified unless that evidence actually exists.

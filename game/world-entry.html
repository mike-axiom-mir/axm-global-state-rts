The host world-hour clock is the chest authority. Re-entry catches up one chest per elapsed world hour, capped at 24 stored chests. Refresh only rechecks that host clock; it cannot double-award the same hour.

Guest state is session-only. A world account can be persisted by the host adapter, but this screen does not prove account ownership, passwords, TLS, anti-Sybil controls, or production deployment.

Continue stores a single-use browser handoff, opens one matching local seat, then the RTS shell re-reads the participant from host authority before binding it. The handoff is a development convenience, not an authentication credential.
